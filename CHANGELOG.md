# Changelog

Semantic Versioning. `MAJOR` reaches 1 when the behaviour is settled enough
to promise not to break it; 0.x is an honest statement that it may still move.

---

## 0.2.0 — 2026-08-21

- **Renamed from "Background - Light" to "Set Background - Colour Light."** The old name only
  read clearly inside a Themes drop-down; this one stands on its own.
- Moved to its own repository, so it is versioned and released independently
  of the other theme macros. The `Source` URL in the header points at the new
  repository.
- No functional change.

## 0.1.1 — 2026-08-20

- The `Source` URL in the header now points at the renamed repository,
  `themes-sw-macro`. No functional change.

## 0.1.0 — 2026-08-09

- First numbered release. Sets Background appearance to Plain and the Viewport
  Background to R:255 G:255 B:255, then redraws the graphics area.
